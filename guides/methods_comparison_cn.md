# 方法对照

只比较本库已下载论文与源码。套件中的对照方法不自动算原作者实现。

## 统计基线

| 方法 | 适用 | 本库入口 | 注意 |
|---|---|---|---|
| 持续性 / 季节持续性 | 任何站点小时序列的第一对照 | 需自行用观测实现；openair 时间平均见 P-08 | 不少深度学习论文未报告，评测不公平 |
| ARIMA/SARIMAX/状态空间 | 单站、外生气象 | P-15 `statsmodels/tsa/` | 多步常为递归；外生变量必须是发报时刻可得 |
| GAM / 线性回归 | 可解释基线 | 待全文核实各论文是否公平调参 | 滞后特征易泄漏 |
| GPR / 时空 GP | 稀疏站、不确定性 | P03-009、P03-010 | 计算成本；空间 GP 常是插值而非预报 |

## 机器学习

树模型、随机森林、梯度提升、SVR、集成。优点是表格特征与缺失处理成熟。本库 LightGBM（P-20）仅为工具库。04 目录论文覆盖站点/城市预测与部分室内任务；室内结果不可与户外法规浓度混评。

公平比较要点：同一时间切分、同一外生变量集合、同一多步协议。用未来真实气象的提升结果，不能直接对标只使用 NWP 的业务模型。

## 深度学习

RNN/LSTM/GRU 适合单站短临；TCN 与线性分解变体见 05 目录；Transformer 以 AirFormer（P02-001，官方代码 P-01）为代表，目标为全国站点未来 72 h。仓库含 tiny demo，完整数据未下载。

基础模型适配（05 查询含 foundation model）摘要层可见，权重未下载，不声称可部署。

## 概率预测

点预测 MAE/RMSE 不能代替超标预警。需要 CRPS、分位数损失、区间覆盖与宽度、高污染事件的检出/误报和样本数。工具库 MAPIE、scores 不是空气质量模型。07 目录篇数少（6），是真实缺口，不是检索失败后的凑数。

## 机理融合

| 角色 | 含义 | 例子 |
|---|---|---|
| 独立预报 | 只用观测/特征，不跑 CTM | 多数深度学习论文 |
| 模式订正 | 对 CTM/CAMS/NAQFC 输出做偏差订正 | P01-002 CAMS 多模式校准 |
| 模式输出当特征 | 把预报场或再分析拼进学习模型 | PCDCNet 用 ERA5；须标信息条件 |
| 可微物理 | 扩散/平流/化学残差进网络 | AirPhyNet、Air-DualODE、PCDCNet |
| 业务 CTM | 数值化学输送本身 | CMAQ、CAMS、NAQFC、WRF-Chem 评估论文 |

PCDCNet README 写明 ERA5 通道与可选排放；这是**事后或许可受限信息条件下的实验**，不能默认等于可部署预报。
