# 空气质量预测资源库（2026-10-30）

本分支 `release-lite-20261030` 是轻量版，只含目录、说明、指南和脚本，不含论文 PDF、教材、离线网页和源码快照。

- **完整内容**在 Release `aqf-full-20261030` 的 3 个 tar 包里：119 篇论文、6 份教材与手册、6 门课程、12 套官方文档离线网页、19 个参考项目源码快照。
- 下载和解压步骤见 [download_restore_cn.md](download_restore_cn.md)。请解压到短路径，例如 `D:\aqf\`。
- 解压后，用浏览器打开 `index_cn.html`，即可离线阅读。本分支里的 `index_cn.html` 只是同一首页的副本，其中的本地链接要在解压后的完整目录里才能打开。
- 资源库说明见 [README_cn.md](README_cn.md)，总目录见 [catalog_cn.csv](catalog_cn.csv)，学习路线见 [guides/](guides/)。
